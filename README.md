# Quiz App

### Project Overview
The **Quiz App** is an interactive and feature-rich Java-based application developed as a **semester project** for the **Object-Oriented Programming (OOP)** course. The app allows users to select quiz subjects, fetch questions dynamically using an API, and evaluate their performance in real-time.

---

### Features
- **Subject Selection**: Choose from multiple subjects (e.g., Math, Science, History) before starting a quiz.
- **API Integration**: Questions are fetched dynamically using an external API for a diverse quiz experience.
- **Multiple-Choice Questions**: Quizzes consist of MCQs tailored to the selected subject.
- **Real-Time Scoring**: Tracks and displays scores after quiz completion.
- **Feedback System**: Highlights correct and incorrect answers with explanations.
- **Object-Oriented Design**: Implements key OOP concepts like encapsulation, inheritance, and polymorphism.

---

### Technologies Used
- **Programming Language**: Java
- **API**: [Open Trivia Database (OpenTDB)](https://opentdb.com/)
- **HTTP Client**: Java libraries for making API calls (e.g., `HttpURLConnection` or `HttpClient`).
- **IDE**: [Visual Studio Code] 
- **File Handling**: To store user scores and settings locally.

### How to Run the Project
1. Clone or download the project repository.
2. Open the project in your preferred Java IDE.
3. Add your API key (if required) in the `config.properties` file or directly in the code.
4. Run the `Main.java` file to start the application.
5. Select a subject and begin the quiz.

---

### API Integration
The app dynamically fetches quiz questions from **Open Trivia Database (OpenTDB)**.  

**Parameters Used**:
- `category`: Subject of the quiz (e.g., Math, Science, History).
- `limit`: Number of questions to fetch.
- `difficulty`: Difficulty level (easy, medium, hard).
